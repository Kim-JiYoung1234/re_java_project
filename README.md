# re_java_project

이전에 진행했던 스프링 부트 프로젝트를 정리합니다.

## 프로젝트 내용

### OFIM - 개인 맞춤형 통합 건강 관리 플랫폼
기간: 2026.02 ~ 2026.03 (약 1개월)
인원: 5인
내용: 사용자 맞춤형 건강 로그 관리, 전문가와 1:1 건강 상담, 피트니스 시설 비교, 커뮤니티 기 등
역할: 사용자 맞춤형 건강 로그 관리 모듈 개발, 공공 데이터 기반 인프라 구축 및 최적화

#### 개발 환경
언어 - JAVA(JDK 21)
프레임워크 - Spring Boot
IDE - Eclipse
빌드 도구 - Gradle
형상 관리 - Git

#### 사용 기술
Backend - Spring Boot, MyBatis
Database - MySQL
Frontend - Thymeleaf, HTML5, CSS3, JavaScript
